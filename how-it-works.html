Code While Claude Code

How it works

Claude Code's turns have dead time. CWCC catches the whole turn — from your prompt to the agent's stop — and fills it with a fast coding drill. Everything runs locally. Press play below.

The window CWCC fills

        

          The key design fact: Claude Code hooks fire on the
          tool lifecycle, not on model reasoning.
        

        

          There is no "started thinking" event. CWCC brackets the
          whole turn between UserPromptSubmit (start) and the top-level
          Stop (end). Subagent stops and agent-tagged stops are ignored so a
          turn never ends early. PreToolUse / PostToolUse are just
          heartbeats — liveness and difficulty hints. Even a pure-reasoning turn with no tools is
          filled end to end.
        

      


      
      

        
Safety by construction

        
Six invariants make CWCC safe to leave running all day.

        

          

            
🚫

            
Never blocks Claude Code

            

              The hook is fire-and-forget: curl caps at 1s and
              || true means it can never fail your turn. Daemon down? The event is
              dropped in ~20ms.
            

          

          

            
🔒

            
Loopback only

            

              Binds to 127.0.0.1, never 0.0.0.0. Every event and WebSocket
              is authed with a local token and an Origin check.
            

          

          

            
📴

            
Fully offline

            

              All 50 challenges ship as JSON inside the package. No network, no LLM calls at play
              time. Works with Wi-Fi off.
            

          

          

            
🪟

            
Never steals focus

            

              The tab updates quietly in the background and never raises itself over your terminal.
            

          

          

            
♻️

            
Reversible install

            

              cwcc install is merge-only, backs up your settings first, and tags its
              own entries. cwcc uninstall removes only those.
            

          

          

            
🤫

            
Fails silently outward

            

              Nothing CWCC does ever surfaces an error into your Claude Code session. All errors go
              to ~/.claude/cwcc/logs/.
            

          

        

      


      
      

        
Three commands to start

        
Needs Claude Code and Node 20+. Full guide in README.md.

        
npm install -g code-while-claude-code
cwcc install        # merges hooks (backed up, reversible)
cwcc start          # then open http://127.0.0.1:9999
